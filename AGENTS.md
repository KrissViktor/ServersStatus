# Назначение проекта

ServersStatus — веб-портал мониторинга серверов на FastAPI и SQLite. Агенты
Windows, Windows Server и Linux отправляют отчёты по исходящему HTTPS:
метрики, диски, службы, бэкапы, процессы и доступную информацию оборудования.
Учитывайте различия ОС; проверка в Linux не подтверждает работу Windows-служб.

# Обязательные ограничения пользователя

- Запрещена перезагрузка ОС серверов при установке и обновлении агентов,
  включая откат и восстановление после ошибки. Не добавляйте и не выполняйте
  прямые, отложенные или косвенные команды перезагрузки. Если продолжение
  требует перезагрузки, остановите этот шаг и обсудите ситуацию с пользователем.
- Обновление агента может перезапускать только его собственную службу.
  Не перезапускайте прикладные службы сервера как часть обновления агента.
- Перезапуск приложения/службы портала разрешён. Это не разрешение
  перезагрузить ОС машины, на которой расположен портал.
- Установка дополнительных драйверов на Linux, Windows и Windows Server
  запрещена без предварительного обсуждения и явного согласования с
  пользователем. Это касается также модулей ядра, драйверов датчиков,
  PawnIO и зависимостей/сторонних компонентов, устанавливающих драйверы.
- Не устанавливайте драйверы автоматически ради получения недоступных метрик.
  Используйте имеющиеся штатные источники ОС; отсутствие датчика допустимо.
- Не выбирайте для установки или отката исторические сборки с автоматической
  установкой драйверов: в истории такой функционал появился в 89dda17 и был
  удалён в 7849c6c. Проверяйте содержимое конкретного пакета и его зависимости.
- Удаление, отключение или изменение уже установленных драйверов также
  предварительно обсуждайте с пользователем.
- Отдельная функция управления перезагрузкой Windows в портале не даёт
  разрешения использовать её: требуется прямое указание пользователя.

# Основные точки входа

- Портал и приём отчётов: `server/app.py`, `/api/report/{agent_id}`.
- Общий сбор и отправка: `agent/client.py`.
- Windows-служба: `agent/windows_service.py`; установка: `agent/installer.py`;
  обновление: `agent/updater.py`, `agent/remote_update.py`, `agent/apply_update.ps1`.
- Linux-служба: `agent/linux_service.py`; отдельный привилегированный
  обновляющий процесс: `agent/update_worker.py`; инструкции: `deploy/LINUX.md`.
- Проверка Windows-пакета на запрещённые компоненты:
  `agent/check_windows_bundle.py` и `.github/workflows/windows-agent.yml`.
- Проверки Python: `.venv/bin/python -m unittest discover -s tests -v`.

Используйте существующий checkout изолированной облачной задачи; не создавайте
Git worktree без явного запроса пользователя. Не сохраняйте ключи агентов,
пароли и содержимое конфигурационных файлов с секретами в Git или выводе.

# Совместимость портала с Python

Портал должен запускаться на Python 3.11. Перед отправкой изменений выполняйте
компиляцию и проверки фактическим интерпретатором Python 3.11. Проверка
`ast.parse(feature_version=(3, 11))` на Python 3.12 не выявляет все изменения
синтаксиса f-строк и не заменяет запуск на 3.11. Не используйте повторное
использование внешних кавычек внутри выражения f-строки; выносите такие
выражения в отдельные переменные. В CI проверка синтаксиса 3.11 уже предусмотрена.
