# Чат с локальной моделью в портале

Связь уже проверена пользователем: на Raspberry Pi
`curl http://127.0.0.1:18091/health` → `{"status":"ok"}`.
Модель работает на Backup/windows-02 через ограниченный обратный SSH-туннель.

## Включить чат

**Ключ не присылать в чат ChatGPT, Telegram, Git или журналы.**
Он передаётся только в локальный защищённый файл на Raspi.

1. Сначала на **Raspberry Pi** обновите портал и запустите настройку:

```bash
cd /opt/ServersStatus
sudo git pull --ff-only origin main
sudo bash /opt/ServersStatus/deploy/ai-ssh/Enable-PortalAI.sh
```

Дождитесь `Paste API key ... (hidden):` и оставьте терминал ожидающим ввода.

2. Теперь на **Backup**, PowerShell от администратора, скопируйте ключ в свой
   буфер обмена (команда не печатает его):

```powershell
Set-Clipboard -Value ([IO.File]::ReadAllText('C:\ProgramData\ServersStatusAI\api-key.txt').Trim())
```

Сразу вернитесь к ожидающему терминалу Raspi, вставьте ключ и нажмите Enter.
Не копируйте другие команды между копированием ключа и его вставкой.

В строке `Paste API key ... (hidden):` вставьте ключ из буфера и нажмите Enter.
Символы не отображаются. Скрипт проверяет health и авторизацию `/v1/models`
(в llama.cpp b12110 этот endpoint требует ключ), затем атомарно сохраняет ключ
в `/var/lib/serversstatus/ai-api-key`, owner `serversstatus`, mode `0600`, и
перезапускает только веб-службу `serversstatus`. При неверном ключе старый файл
не заменяется. Ключ не попадает в аргументы curl и внешний HTTP proxy.

3. Войдите в портал как администратор и откройте **«ИИ-помощник»** вверху или:

```text
https://panel.vikserver.ru/ai
```

После настройки можно очистить локальный буфер Windows:

```powershell
Set-Clipboard -Value ''
```

Модель, Windows-службу и SSH-туннель обновлять не требуется.
Новые зависимости и изменения Caddy не нужны.

## Возможности чата

- Постепенный вывод ответа, Enter/Shift+Enter, сохранение черновика.
- Новый диалог, мгновенное переключение истории, отмена ответа и удаление диалога.
- История строго своей учётной записи, до 186 дней; при удалении пользователя
  его AI-история также удаляется, чтобы новый аккаунт с тем же именем её не получил.
- Администратор/суперадмин; роль текущего просмотра не получает доступ к чату.
  Console-unlock не нужен: помощник только формирует текст, команды не исполняет.
- До 50 диалогов и 50 вопросов в каждом, один незавершённый запрос на пользователя,
  до трёх запросов в общей очереди, один активный запрос к модели.
- Контекст — system prompt, текущий вопрос и до четырёх последних полных пар
  текущего диалога, с лимитом 8000 символов (5000 при инструментах). Максимум 4000 символов на вопрос,
  512 новых токенов, 180 секунд обработки (300 при инструментах), до 16384 символов сохранённого ответа.
- Ответы — безопасный текст, без исполнения HTML или команд.

## Метрики, журнал и интернет

«Серверы и журнал» включено в форме по умолчанию. Помощник получает только
чтение: текущие CPU/RAM, диски и бэкапы, последние процессы и службы,
сводку CPU/RAM и события за 1–168 часов. Записи консоли и управления
пользователями не выдаются. Служебные ключи и командные строки не передаются.
Время источников указывается с часовым поясом +03:00. Это последние полученные
данные, а не подключение модели к ОС. Полный список процессов ограничен топ-12,
служб — 25, событий — 25; объём ответа инструмента ограничен.

«Интернет» включён по умолчанию; его можно отключить для вопроса. Поиск
по умолчанию выполняется через API Tavily, не через HTML-страницу Google.
В запрос передаётся текст вопроса или необязательный отдельный запрос (до
300 символов), без автоматически добавленных метрик, журнала или истории.
Модель не может дописать данные портала к поисковому запросу.

Tavily возвращает ссылки, фрагменты и извлечённый текст страниц. Текст двух
первых источников передаётся модели перед ответом; повторно скачивать эти
страницы с Raspi не нужно. Для пользовательской ссылки сначала пробуется
обычное чтение; если оно не удалось, вызывается API извлечения Tavily с проверкой
публичности адреса. Под ответом видны источники и ошибки. API по-прежнему может
не получить закрытую/защищённую страницу; успешный ответ на любой вопрос не
гарантируется. Данные источников считаются недоверенными инструкциями.

Нужен исходящий HTTPS к api.tavily.com; используется существующая
STATUS_AI_WEB_PROXY. Ключ модели туда не передаётся. Режим поиска виден в чате.
Первый запуск использует официально предусмотренный Tavily keyless-режим.
Доступность и лимиты анонимного режима определяет Tavily; при 401/403/429 и
других ограничениях нужен личный ключ или ожидание сброса лимита. Ограничения
не обходятся сменой IP/прокси. Тарифы и квоты смотрите в своём аккаунте сервиса.

Ключ можно подключить после создания аккаунта на https://app.tavily.com/:

```bash
sudo bash /opt/ServersStatus/deploy/ai-ssh/Enable-AISearch.sh
```

Скрытый ввод, пустой Enter отменяет изменение. Скрипт проверяет только формат,
атомарно сохраняет /var/lib/serversstatus/ai-search-key (owner serversstatus,
0600) и перезапускает веб-службу. Проверка действительности — на первом поиске.
Ключ не присылать в переписку/Telegram/Git. Файл отдельно от ключа локальной
модели; STATUS_AI_SEARCH_KEY_FILE позволяет указать иной серверный путь.

Проверка API из каталога репозитория (ничего секретного не печатается):

```bash
sudo -u serversstatus env STATUS_AI_WEB_PROXY=socks5h://127.0.0.1:1080 /opt/ServersStatus/.venv/bin/python -m server.ai_search
```

Укажите свой порт прокси. Для прямой проверки задайте STATUS_AI_WEB_PROXY=.
Команда выполняет один реальный запрос, расходуя квоту сервиса. Стандартные
новые Python-зависимости не требуются. Прежний Google HTML-парсер оставлен
только как явно выбранный старый режим STATUS_AI_SEARCH_PROVIDER=google;
по умолчанию tavily, автоматического возврата к HTML Google нет.

При чтении проверяются публичность URL/DNS, redirects, сертификат; запрет
метаданных/локальной сети сохранён. API-ключ уходит только фиксированному
api.tavily.com, redirects API запрещены, ответ ограничен 2 МБ; обычная страница
512 КБ. Шесть инструментов на вопрос; история источников приватна, до 186 дней.

1С, файловые журналы Windows/Linux, консоль и управление не подключены.
Обновлять Windows-агенты, модель или SSH-туннель для этой функции не нужно.
Проверка после обновления: «Какие серверы отключены? Проверь журнал за сутки».
Для проверки интернета введите запрос «Windows SQL backup error» и попросите
найти материалы. Здесь вызовы инструментов проверены искусственным SSE;
реальную работу Qwen и доступ к поисковику нужно проверить на вашей Raspi.

## Как работает

Портал обращается только к фиксированному `http://127.0.0.1:18091`, передавая
ключ из локального файла. URL/ключ не отправляются браузеру, redirect и внешний
proxy отключены. Отдельный фоновый обработчик читает OpenAI SSE и сохраняет
части ответа; браузер получает их короткими запросами примерно раз в секунду.
Поэтому Caddy с прежними 15/30-секундными таймаутами менять не требуется и
генерация не держит долгие HTTP-запросы браузера.

Повтор отправки с тем же nonce не создаёт двойного запроса. Отмена закрывает
поток модели, завершённые ответы и приватная история не смешиваются между
пользователями. После рестарта незавершённый ответ отмечается как прерванный,
не воспроизводится автоматически. Ключ хранится отдельно от базы и истории.

## Диагностика

- Нет настройки: проверьте существование/права `ai-api-key`, повторите скрипт.
- Нет связи/модель приостановлена: проверьте health, туннель и RAM/паузу Backup.
- Модель отклонила ключ: снова перенесите правильный ключ с Backup.
- Длинный запрос: сократите вопрос/контекст или начните новый диалог.
- Для локального ручного выбора другого key-file администратор может задать
  `STATUS_AI_KEY_FILE` в окружении веб-службы. Браузер этот путь не задаёт.

В тестах используется искусственный SSE-сервер/transport, не реальная модель
пользователя. Финальную скорость и работу через ваш туннель проверим первым
вопросом в портале после переноса ключа.

## Быстрый чат на любой странице

На страницах портала для администраторов доступна кнопка «ИИ-помощник» внизу
справа. Чат открывается поверх страницы и загружается только при первом
открытии. Кнопка «−» и Escape сворачивают окно, сохраняя черновик, переписку
и выполнение текущего ответа. Страница остаётся на месте. «↗» открывает полную
версию /ai. После перехода на другую страницу при открытии загружается история
учётной записи; несохранённый черновик между переходами не переносится.
В компактном окне поиск использует вопрос, отдельное поле доступно на /ai.

## Погода без зависимости от поисковых сниппетов

Для вопросов о погоде при включённом интернете портал напрямую получает
структурированный прогноз Open-Meteo (geocoding-api.open-meteo.com и
api.open-meteo.com, исходящий HTTPS). Это источник метеоданных; обычный поиск
по умолчанию выполняется через Tavily. Для Open-Meteo отдельный ключ не нужен.
Город берётся из пользовательского вопроса; метрики и журнал туда не отправляются.
Названия приводятся к именительному падежу локальным словарём pymorphy3:
«в Мытищах» → «Мытищи», «в Нижнем Новгороде» → «Нижний Новгород»,
«в Великих Луках» → «Великие Луки». Учитываются род/число прилагательных,
части «-на-Дону»/«-на-Амуре» сохраняются. Исходное написание используется как
резервный запрос, если нормализованное имя не найдено; неизвестные слова не
исправляются выдуманным обрезанием окончаний. Ответ показывает найденный город,
регион и страну. Полнота словаря и геосервиса не гарантирует распознавание всех
поселений; неуказанный/ненайденный город даёт просьбу уточнить название/регион.
Поддержаны сегодня/завтра/послезавтра и точная дата в ближайшие семь дней.
Дата считается по часовому поясу места, проверяется наличие всех показателей.
Ответ содержит минимум/максимум температуры, вероятность/сумму осадков,
максимальный ветер, время получения и источник. Числа форматируются напрямую,
без интерпретации моделью. При сетевой ошибке показывается причина и не
выдумывается прогноз. Доступность сервиса зависит от сети Raspberry Pi.

## Сетевые ошибки и локальный VPN-прокси

Интернет-инструменты по умолчанию подключаются напрямую и не наследуют
HTTP_PROXY/HTTPS_PROXY или STATUS_TELEGRAM_PROXY. Для сети с ограничениями
можно отдельно включить уже работающий локальный Hysteria SOCKS-прокси только
для чтения сайтов/поискового API/Open-Meteo. Подключение к модели 127.0.0.1:18091,
приём отчётов и остальные запросы не переключаются на этот прокси.

При стандартной установке веб-служба уже читает /etc/serversstatus-telegram.env.
Добавьте в этот файл, сохранив существующие строки:

```dotenv
STATUS_AI_WEB_PROXY=socks5h://127.0.0.1:1080
```

Перезапустите `sudo systemctl restart serversstatus`. Допустим только локальный
HTTP/HTTPS/SOCKS5/SOCKS5h proxy без пароля. Укажите фактический порт клиента,
если вместо 1080 используется другой. TLS-проверка не отключается, публичный IP
проверяется и фиксируется до подключения, redirects проверяются повторно.
Для отключения удалите только STATUS_AI_WEB_PROXY и перезапустите веб-службу.

Безопасная проверка (из каталога репозитория; без ключей модели/бота):

```bash
sudo -u serversstatus env STATUS_AI_WEB_PROXY=socks5h://127.0.0.1:1080 /opt/ServersStatus/.venv/bin/python -m server.ai_web
```

Вывод содержит три источника (геокодирование, прогноз, Google), HTTP-статус/
тип и длину либо конкретную ошибку. HTTP 200 Google сам по себе не гарантирует
читаемую выдачу — CAPTCHA/JavaScript определяются при выполнении поиска.
Чтобы проверить прямой путь, замените значение на `STATUS_AI_WEB_PROXY=`.
В ошибках указаны домен и прямой/прокси путь; URL запроса/учётные данные и
сырой текст исключений не печатаются. Таймаут подключения — 8 с, чтения — 15 с.
При ошибке TLS проверьте `timedatectl status` и пакет `ca-certificates`,
не отключайте проверку сертификатов. Недоступный DNS по-прежнему даст отдельную
ошибку: локальная проверка публичности адресов обязательна даже при SOCKS5h.


## Самостоятельное чтение сайтов и курсы валют

При сбое поискового API портал автоматически просит модель выбрать до двух известных
публичных сайтов. Этот выбор выполняется отдельно: модель видит только вопрос,
без истории диалога, метрик и журнала. Выбранные адреса проверяются теми же
ограничениями публичности, портов, DNS, redirects и TLS. Данные сайтов считаются
недоверенными. Сама подсказка адреса не считается подтверждённым фактом —
нужно успешное чтение страницы. Модель может повторно вызвать web_discover,
если выдача не подходит. Поиск по умолчанию выполняет Tavily, Google HTML — только явно включённый старый режим.

Из прочитанного HTML извлекаются до восьми ссылок, каждая получает ID W#.
Модель может переходить по этим ID и читать следующие страницы. Произвольные
URL из контекста метрик не передаются напрямую в интернет. До шести инструментов
на вопрос, четыре раунда модели, суммарно до 9000 символов результатов.
Произвольный JavaScript, формы входа, скачивание файлов и браузерные CAPTCHA
не исполняются: это чтение публичного HTML/JSON/XML, а не полноценный браузер.

Для курса валют к рублю используется официальный XML Банка России:
https://www.cbr.ru/scripts/XML_daily.asp. Поддерживаются USD/EUR/CNY/GBP/CHF/
TRY/AED/KZT/BYN/JPY, по общему вопросу — USD/EUR/CNY. Ответ показывает дату
действия, цену за одну единицу с учётом Nominal, источник и явную пометку:
официальный курс, не курс покупки/продажи банка. Текущая публикация ЦБ может
действовать несколько дней; не выдаётся за биржевую котировку в реальном времени.
Курсы выводятся напрямую из проверенных чисел, без зависимости от поисковой выдачи.
Неполный XML, недопустимые числа и внешние XML entities не принимаются.

### ЦБ недоступен через VPN

Если официальный www.cbr.ru выдаёт сетевую/TLS-ошибку через настроенный локальный
прокси, модуль курсов повторяет запрос к тому же фиксированному HTTPS-адресу
напрямую. У российского сайта маршрут через зарубежный VPN может быть недоступен;
это возможная причина, не диагноз сети пользователя. Оба маршрута сохраняют
проверку DNS/public IP, redirects и сертификата. Ограничения публичности URL и
ошибки содержимого/XML не обходятся. Если прямой запрос тоже не прошёл, ответ
содержит обе ошибки. Для прочих сайтов и подключения модели маршруты не меняются.
Новых переменных окружения и изменений VPN не требуется.


### Обновление словаря городов на Raspi

При обновлении портала установите новые серверные зависимости:

```bash
cd /opt/ServersStatus
sudo git pull --ff-only origin main
sudo /opt/ServersStatus/.venv/bin/python -m pip install -r requirements.txt
sudo systemctl restart serversstatus
```

pymorphy3 и словарь русского языка работают локально на Raspberry Pi.
Отдельная модель, поисковый API и передача текста стороннему ИИ для склонений
не требуются. Windows-агенты, модель на Backup и прокси обновлять не нужно.
Словарь загружается при первом запросе русского названия и используется повторно.
Примеры: «Погода на завтра в Мытищах», «Погода в Набережных Челнах»,
«Погода в Ростове-на-Дону». Формы без предлога («Погода Мытищи») также допустимы.
