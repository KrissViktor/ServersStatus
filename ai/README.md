# Локальный помощник: этапы

Выбран сервер **windows-02 / WIN-CU629F0N7II («Backup»)**,
Windows Server 2022, i7-12700K, встроенная графика.

1. **Сейчас подготовлено:** CPU llama.cpp, Qwen3-14B Q4_K_M, ограниченная
   Windows-служба и локальный тест. Установка: [инструкция](../deploy/ai-windows/README.md).
2. Локальный запуск подтверждён пользователем: 6,27 токена/с, ответ за 4,9 с.
   Привязка паузы к реальным бэкапам ещё ожидает уточнения программы.
3. Выбран обратный SSH: [инструкция](../deploy/ai-ssh/README.md). Windows сама
   подключается к Raspi через домашний TCP 2222; Tailscale не требуется.
   Пользователь подтвердил health через SSH. **Чат реализован**:
   [включить ключом на Raspi](../deploy/AI-CHAT.md).
4. Реализованы инструменты чтения метрик и журнала портала, поиск и чтение
   публичных страниц с источниками: [возможности](../deploy/AI-CHAT.md).
5. Подключение 1С отложено пользователем на будущее.

Помощник не получает консоль, ключи агентов или чтение файлов автоматически.
